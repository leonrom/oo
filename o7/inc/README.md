# inc

Feature-модуль для обработки аудио-ссылок и аудио-тегов.

## Ответственность

- вставка html-файлов или их фрагментов в document

## Алгоритм

1. Просмотр тегов с атрибутом o_include. Эти теги _должны_ содержать уникальные идентификаторы id

Значение ref атрибута o_include _должно_ содержать (относительный) адрес загружаемого файла, после которого _может_ быть символ '?' , после которого _может_ быть селектор sel выборки "считываемого и вставляемого"  фрагмента.

у разных тегов могут повторяться url и sel. 
sel может содержать буквено-цифрову часть 'name' и символы '.', '#', '!' 
Если 'name' отсутствует то берётся содержимое тега body (скачанного файла).
Наличие (в любом месте селектора) симолов  '.', '#', '!' интерпретируется: 
- '.',- берутся (и вставляются!) теги с classList.includes(name)
- '#',- берутся теги  с id==name (id не обязательно уникальны)
- '!',- вставляется весь тег, иначе - его содержимое

определяются url файла с которого будет загрузка и селектор для выборки фрагмента из этого файла

Формируются списки: 
- уникальных url'ов для загрузки. Он  может быть вставлен целиком или частями;
- уникальных фрагменов из url'ов. Фрагмент может быть одним или несколькими (в зависимости от селектора)частями загруженно файла;
- список тегов, в который производилась вставка. Каждая вставка в теге ограничена служебными комментарими

## Экспорт

Модуль экспортирует функцию:

- prepare() — точка инициализации
