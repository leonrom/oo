# pop — pop-up windows manager

Feature-модуль организации всплывающих окон (подсказок)

## Ответственность

- вызов подсказок по клику, по dblclick и по наведению курсора (с задержкой)

Если задано "по наведению курсора" (т.е. квалификаторы 'O' или 'A') то всплытие также будет и по клику. Отличие между 'O' и 'A': если 'O' и всплыло не "по клику" то при уводе курсора окно закроется автоматически. Во всех остальных случаях окно закрывается по click/dblclick

## Экспорт

Модуль экспортирует функцию:

- prepare() — точка инициализации
