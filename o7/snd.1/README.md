# snd — sound synchronization module

Feature-модуль для обработки аудио-ссылок и аудио-тегов.

## Ответственность

aO7 = new AO7(el) создаётся при первом hover

один URL на элемент

играет только один звук во всём документе

любые <audio> (твои и чужие) взаимно гасят друг друга

при hover — только загрузка

play → останавливает всё остальное

DOM не меняем

модуль должен уметь очищаться

## Экспорт

Модуль экспортирует функцию:

- prepare() — точка инициализации
