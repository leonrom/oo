# snd — sound synchronization module

Feature-модуль для обработки аудио-ссылок и аудио-тегов.

## Ответственность

- подготовка ссылок на аудио
- синхронизация звучаний
- иконки и визуальные маркеры

## Экспорт

Модуль экспортирует функцию:

- prepare() — точка инициализации

## Состав

 │
 ├─ snd/                // обработка ссылок на аудио - синхронизация звучаний
 │    ├─ snd.js
 │    ├─ Init.js     - определение списков аудио-тегов (CAO7, TAO7)
 │    ├─ TAO7.js     - общее описание аудио-тегов (AO7, Play)
 │    ├─ СAO7.js     - общее описание аудио-тегов (AO7, Play, Pick)
