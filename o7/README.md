# o7

Модульная ESM-библиотека для расширения поведения HTML-документа
через подключаемые feature-модули.

## Архитектура

Библиотека состоит из трёх уровней:

1. Точка входа
2. Общие c-модули (common modules): com, dbg
3. Функциональные f-модули (feature modules): inc, mnu, pop, ref, shp, snd, tab

## Структура каталогов

o7/
 ├─ index.js        — точка входа, orchestrator
 │                  • читает параметры из <script>
 │                  • динамически загружает f-модули
 │                  • управляет порядком инициализации
 │
 ├─ com/            — common-модули
 │                  • формируют объект C (общее API)
 │                  • не зависят от f-модулей
 │
 ├─ dbg/            — отладочные модули
 │                  • опциональны
 │                  • могут подключаться через com
 │
 ╘= inc/, ... tab/  — feature-модули
        • каждый модуль независим и содержит описатель W
        • W содержит обязательные объекты:
            - modul: наименование модуля (ini, snd, etc.),
            - act: различные параметры текущего состояния,например { runId: 0, auto: -1 }, из них 'autoi' является обязательным
            - init() выполняется при каждой инициализации страницы 
            - finish() выполняется при завершении инициализации и, как минимум, вызывающая window.dispatchEvent(new CustomEvent('o_done', { detail: { modul: W.modul, err: false } })) чтобы сообщить ядру библиотеке о завершении инициализации

        а так же необязательные объекты: 
            prepare() выполняется 1 раз при загрузке скрипта
            reset() принудительно освобождает использованные ресурсы перед повторными инициализациями страницы
            makeCss() - возвращает текстовую строку, содержащую CSS-правила для вставки в <head> (в дополнение к <linc>)
        Имя ассоциированного класса всегда будет (если будет)
		    clasn= 'olga-' + modul

Повторные инициализации страницы происходят, например, в Blogger'е,- когда меняется содержимое HTML документа
