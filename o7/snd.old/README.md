# snd — sound synchronization module

Feature-модуль для обработки аудио-ссылок и аудио-тегов.

## Ответственность

- подготовка ссылок на аудио
- синхронизация звучаний
- иконки и визуальные маркеры

## Экспорт

Модуль экспортирует функцию:

- prepare() — точка инициализации

## Состав

 │    ├─ snd.js
