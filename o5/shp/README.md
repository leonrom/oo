# snd — sound synchronization module

Feature-модуль для обработки аудио-ссылок и аудио-тегов.

## Ответственность

- обработка "зависаний" тегов на границах контейнеров

## Экспорт

Модуль экспортирует функцию:

- init() — точка инициализации

## Состав
 
 ├─ shp/
 │    ├─ shp.js         // основной 'index'-файл
 │    ├─ AO5shp.js      // класс AO5 описания "зависабельных" тегов
 │    ├─ DoChgs.js      // обработка изменеий скроллинга
 │    ├─ DoInit.js      // выборка зависабельных тегов в документе
 │    ├─ Frames.js      // класс типов зависаний - определяет подходящие контейнеры
 │    ├─ PBases.js      // класс базового контейнера
 │    └─ PO5shp.js      // класс PO5 описания контейнеров, на которых м.б. aO5
