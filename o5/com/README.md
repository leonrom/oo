# com — common modules

Модули общего назначения.
Формируют объект `C`, который используется всеми feature-модулями.

## Принципы

- com НЕ импортирует feature-модули
- com не знает, какие f-модули будут подключены
- весь API экспортируется явно через `C`

## Состав

- CApi.js       — общие утилиты
- CConsol.js   — цветной лог
- CEncode.js    — кодирование URL и ресурсов
- CParams.js    — разбор параметров <script>
- IniScripts.js — контроль инициализации и перезагрузки

 │
 ├─ com/                // API функции, добавляемые в C{}
 │    ├─ index.js
 │    ├─ CApi.js        // сборник функций 
 │    ├─ CConsol.js    // "расцвеченый" вывод отладочных сообщений
 │    ├─ CEncode.js     // перекодирование url-адресов по адресным константам
 │    ├─ CParams.js     // парсинг пераметров из тега <script>
 │    │    
 │    └─ IniScripts.js  
 │
 Скрипты CApi.js, CConsol.js, CEncode.js, CParams.js формируют C, а последний скрипт IniScripts.js выполняет  контроль (пере)загрузки страницы и "поочередной" запуск подключаемых f-модулей
