Формирование HTML-таблиц

Скрипт tab.js подменяет использование тега <table>.

В отличие от большинства скриптов библиотеки Olga5  данный скрипт может использоваться автономно,- как без подключения ядра com!.js так и при его подключении, но при этом скрипт д.б. размещен выше скрипта ядра.

Стандартный тег <table> создания таблиц несколько неудобен при просмотре HTML-документа в текстовом редакторе, т.к. структура таблицы труднообозрима. Поэтому, для организации таблиц, предлагается использовать атрибут <pre> с атрибутом o5table.

Кроме наглядности представления таблицы в HTML-файле использование атрибута o5table позволяет реализовать сортировку таблицы по произвольным столбцам. Так он может иметь значение, равное столбцу сортировкиь строки таблицы, наприимер o5table='2' отсортирует строки по второму (слева) столбцу. Значение '0', как и его отсутствие, преобразовывает строки без их сортировки.

Модуль находит (в областях действия инициализации данного скрипта) все теги с атрибутом o5table и заменяет их тегами table, наполняя их т.с. соответствующей начинкой: построчно разбивая их содержимое на ячейки.

Для разбивки строки разделяются как символом концы строки '\n', так и специальным символом '¶' (182),- здесь и далее в скобках указан HTML-код. Эти разделители можно использовать одновременно, т.к. пустые строки игнорируются. Строки с первым значащим символом '#' считаются комментаниями.

Строки, начинающиеся символом '§' интерпретируются как заголовки таблицы, при этом сам символ игнорируется. Заголовкам можно присвоить комментарии, всплывающие при наведении курсора. Для этого нужно вставить (желательно - перед заголовком) строки содержащие смивол '¿', который разделяет вставляемые строки на две части: слева - номер столбца, а справа - текст комментария.

В каждой строке текст разбивается по ячейкам, при этом содержимое ячейки:

  • должно оканчиваться символом разделения или объединения ячеек:
    • ▸ (9656) раздельно с ячейкой справа;
    • ▹ (9657) слитно (без вставки пробела) с ячейкой справа;
    • ᐞ (5150) слитно с ячейкой сверху

    Слева от символов '▸' и '▹' должен обязательно быть хоть один пробел.

  • может содержать символы его горизонтального выравнивания, отличные от действующих CSS-правил таблицы:
    • ↢ (8610) выравнивание влево
    • ⇔ (8660) выравнивание по центру
    • ↣ (8611) выравнивание вправо
  • добавлены символы форматирования текста:
    • ₔ (8340) запись последующего символа в верзнем регистре, заменяя использование тега <sup> для отдельного символа

Любое слово непосредственно слева от символа '▸' интерпретируется как часть наименования класса ячейки <td>. Например для 'ффф 1x3▸' интерпретируется как <td class tab-td_1x3>.

Сами строки могут начинаться символом '▸', к которому аналогично (предыдущему абзацу) слева может непосредственно примыкать наименование класса - для всего рядка <tr>. Например, 'y14▸' будет интерпретировано как <tr class tab-tr_y14>

Если символ выравнивания является единственным значащим сиволом в ячейке, то такая ячейка игнорируется, а выравнивание задаётся целому рядку таблицы. Например, записав в конце строки ' 🢝 ⇔' мы выровняем все её ячейки по-середине.

Эти символы могут быть заменены заднием 8-словного тегового атрибута o5tag_table содержащего все перечисленные символы в последовательности "§¶▸▹↢⇔↣ₔᐞ"

При замене (найденых тегов на теги table) все их атрибуты, кроме o5table, без изменений копируются в создаваемый тег table. Также без изменений копируются атрибуты. Дополнительно задается свойство opacity=1,- чтобы в исходном теге можно было записать style="opacity: 0;" для избежания мигания таблицы.
